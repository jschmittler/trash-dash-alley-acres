# Reusable Trash Dash Environment Concept Prompt

Create **five connected environment concept images** for a Trash Dash level.

## Inputs
- Level: `[LEVEL NUMBER + NAME]`
- World/theme: `[THEME]`
- Time/lighting progression: `[LIGHTING]`
- Scene 1: `[SCENE]`
- Scene 2: `[SCENE]`
- Scene 3: `[SCENE]`
- Scene 4: `[SCENE]`
- Scene 5/finale: `[SCENE]`

Use the established Trash Dash environment style: richly painted, atmospheric, slightly exaggerated, abandoned/overgrown/trash-filled environments that feel inviting to explore rather than grim horror.

Generate each scene as its own wide inspiration image. The five scenes must be obviously different while still reading as one continuous journey. Repeat a few architectural/material cues across scenes to connect them.

This is reference art for a **2.5D side-scrolling platformer**, not a literal gameplay screenshot. Compose every image so it clearly establishes four useful depth layers: **ground/gameplay plane**, **close background**, **medium background**, and **distant background**. Include obvious ledges, platforms, routes, props, elevation changes, landmarks, and negative space that could inspire side-scrolling traversal without forcing the image into a rigid orthographic side view.

Do not include main characters or enemies unless explicitly requested. Avoid text-heavy signage. Preserve strong silhouettes and readable material separation so Codex can translate the scene into layered runtime art.
