# Trash Dash Canonical Design Decisions

1. This package supersedes earlier conversation-only references for the assets it contains.
2. `docs/game/levels.md`, `docs/game/enemies.md`, and `docs/game/foreground-assets.md` are the canonical written guides.
3. `reference/` contains approved visual source material.
4. `archive/` contains superseded or alternate concepts and must never override canonical assets.
5. Fox is removed. Bee belongs to Level 2, not Level 1.
6. Level 1 standard roster: Spider, Pigeon, Mosquito, Opposum/Pilfer, Snake.
7. Level 2 standard roster: Squirel, Dog, Skunk, Moth/Dustwing, Bee. Brutus the Bin-Hound is the approved boss.
8. Level 3 roster: Alley Cat Burglar, Traffic-Cone Crab, Sewer Rat Courier, Subway Roach, Pizza Rat King boss.
9. Level 4 roster: Clipboard Hamster, Mop-Bot 3000, Beaker Slime, Phase Gecko, Project O.P.O.S.S.U.M. boss.
10. Level 5 roster: Satellite Hermit Crab, Asteroid Armadillo, Vacuum Jelly, Rocket Roach, Galactogobbler boss.
11. Secret Level 6 roster: Baserunning Beaver, Sliding Seagull, Windup Weasel, Clobbering Cub, The Diamond Don boss.
12. Secret Level 6 access method remains TBD.
13. Sprite sheets are source art, not automatically runtime-ready atlases. Codex must validate/slice them before implementation.
14. Level 1 boss art and Brutus boss art are now included in this package as approved concept/reference sheets.
