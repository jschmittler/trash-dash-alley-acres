# Level layout guidance

The approved current layout direction is `reference/level-layouts/dynamic-approved/`.
These six files replace the earlier more-uniform canonical layouts.

Codex should treat them as directional blueprints, not literal collision maps.
Required interpretation:
- preserve the unique traversal identity of each level
- preserve approved enemies, bosses, collectibles, Taco/Kite power-ups, and the standard dumpster reward
- fit the art and placement into the current game code, camera, collision, and platforming constraints
- keep the skills and runtime rules authoritative for object spacing, grounding, collision, parallax, readability, and performance

The older layouts are preserved under `reference/level-layouts/superseded-canonical-v1/` only for historical reference.
