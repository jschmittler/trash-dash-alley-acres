# Approved asset policy

## Use this first
1. `reference/characters/**` for enemies and bosses.
2. `reference/main-characters/**` for Trashy and Jimothy.
3. `reference/environments/**` for environmental concept art.
4. `reference/foreground-assets/**` for level filler props.
5. `reference/items/**` for collectibles and power-ups.
6. `reference/gameplay-tiles/**` for grounded platform and hazard direction.
7. `reference/ui-powerups/**` for Taco Power and Kite Power splash screens.
8. `reference/rewards/**` for the level-complete dumpster reward.
9. `reference/level-layouts/dynamic-approved/**` for current level flow direction.

## Do not treat as current source of truth
- `archive/**`
- `reference/level-layouts/superseded-canonical-v1/**`
- any loose early sprite-sheet alternates not included under `reference/`

## Interpretation guidance
All reference artifacts are directional design input. Codex should use them together with the project's skills and current runtime limitations. Preserve approved character identities, items, power-up rules, reward logic, and level themes, but fit them into the actual engine structure and gameplay constraints.
