# Trash Dash Main Character Approval Ledger

Status: **APPROVED FOR CANONICAL SOURCE-OF-TRUTH IMPORT**

This folder pins the exact approved character concepts and sprite-reference sheets for the two playable characters. Earlier generated passes are superseded and must not be used for implementation, extraction, animation mapping, or visual reference.

## Canonical concepts

- `concepts/trashy-regular-and-powered-approved.png`
  - Regular Trashy: compact, small, agile base form with yellow scarf, blue pants, utility belt, and full striped tail.
  - Powered-Up Trashy: taller and substantially more muscular taco-powered form, same identity and outfit language.
- `concepts/jimothy-regular-and-powered-approved.png`
  - Regular Jimothy: unusually long legs, short spine, high rounded back, teal scarf and satchel.
  - Powered-Up Jimothy: same odd proportions, but feral, electrically charged, spiked fur, and manic expressions.

## Superseded material

All earlier Trashy and Jimothy sprite-sheet attempts from this conversation are **REJECTED / SUPERSEDED**, including:

- sheets where characters turned away during kite flight,

- all intermediate Jimothy and Trashy passes created before the four approved files above.
