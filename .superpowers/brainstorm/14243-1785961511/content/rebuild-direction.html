How far should the hero rebuild go?

All three approaches fix cell size, baseline, centering, and state naming. The difference is how much we redraw.

A — Extraction cleanup

Keep every existing drawing untouched and isolate the cleanest available poses. Fastest, but missing actions remain limited by the source sheet.

B — Hybrid rebuild (recommended)

Lock the current face, costume, palette, and personality; redraw or repair only the poses needed for complete small/large animation sets.

C — Full sprite redesign

Rebuild the hero from scratch with a stricter SNES-era silhouette and palette. Maximum consistency, largest change from the character you already like.

My recommendation: B

  • Keeps the raccoon recognizable
  • Supports every required action
  • Lets us enforce one baseline and scale system

Tradeoff

  • Some rebuilt frames will not be pixel-identical to the original sheet
  • Requires a new canonical atlas rather than more raw crops
