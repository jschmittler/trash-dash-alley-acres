# Generation prompts

## Decorative props

Use case: stylized-concept. Asset type: game decorative sprite source sheet. Create a 3-column by 2-row sheet in exact order: bush, tree, recycling bin / crate, trail sign, tires. Use strict side-on orthographic 16-bit pixel art, shared baseline, crisp edges, generous padding, and a flat `#00ff00` chroma-key background. Avoid perspective, top faces, floating, clipping, gradients, text, labels, and watermarks.

## Branch platform

Use case: stylized-concept. Asset type: game platform source strip. Create a strict side-on horizontally tileable grass-and-soil strip with a green cap and warm brown soil/root texture on flat `#00ff00`. Avoid end caps, gaps, clipping, floating, perspective, text, and watermarks.

## Metal platform

Use case: stylized-concept. Asset type: game platform source strip. Create a strict side-on horizontally tileable slate-gray riveted metal strip with subtle panel seams and scratches on flat `#00ff00`. Avoid end caps, gaps, clipping, floating, perspective, text, and watermarks.
